## 可视化证据规范（2026-07-16）

为避免将不同类型的门控统一误画成 CAM 热图，后续实验展示统一按模块机理区分：

1. `DWGConv / DWGConvMS / DWGConvSA.channel_gate`
   这类门控是全局通道系数，不应再解释为空间注意力热图。
   推荐证据：按云层、建筑、植被、天空等场景绘制门控条形图或权重分布图。

2. `MDHIFI.noise_gate`
   该门控保留空间维度，可以绘制空间 Gate 热图。
   热图下需同步报告 `Target-to-Clutter Response Ratio (TCRR)`，把“目标更亮”转成可量化证据。

3. `HFSCC.consistency`
   优先展示跨尺度一致性图 `C_{i,i+1}`，例如 `c4/c5`，说明目标区域获得补偿、无支持杂波被抑制。
   同样需要同步报告 TCRR。

4. Tiny 目标尺寸分层
   整体 mAP 不能单独证明 tiny 目标获益，后续结果需要补充 `1–4 / 5–8 / 9–16 / >16 px` 的尺寸分层统计。

当前仓库已补充以下脚本以支持上述分析：

- `scripts/analyze_module_responses.py`
- `scripts/eval_size_stratified_ap50.py`

## 0705-b5-3 可视化与尺寸分层表述草稿（论文/答辩可直接复用）

### 图注草稿 1：MDHIFI 空间 Gate 与 TCRR

**图 X. MDHIFI 空间门控响应可视化与目标-杂波响应比（TCRR）对比。**
图中展示了 `0705/b5-3` 模型在 `building`、`cn_sky`、`jungle`、`urban-areas` 和 `cn_mountains` 等典型空域场景下的 MDHIFI 空间 Gate 响应。由于 MDHIFI 的 `noise_gate` 保留空间维度，因此其热图能够直接反映目标区域与背景区域的差异性增强。结合 TCRR 指标可以看到，模型在 `urban-areas` 和 `jungle` 等复杂纹理场景中对目标区域的响应更集中，而在 `cn_sky` 等低纹理背景中响应增益相对有限，说明该模块更擅长在复杂背景下突出真实目标并抑制杂波干扰。

### 图注草稿 2：HFSCC 跨尺度一致性图与 TCRR

**图 Y. HFSCC 跨尺度一致性图 `C_{i,i+1}` 可视化及其 TCRR 统计。**
图中给出了 HFSCC 模块的一致性图 `c4` 与 `c5`。与传统 CAM 不同，这里直接展示的是跨尺度补偿置信图：高响应区域表示该位置在相邻尺度间获得了稳定支持，因此会被补偿增强；低响应区域则意味着缺乏跨尺度支持，更可能被视为背景杂波并受到抑制。实验结果表明，`c4` 在 `urban-areas` 与 `cn_mountains` 场景中取得更高的 TCRR，说明 HFSCC 在复杂背景和结构化边缘场景下能够更有效地为目标区域提供跨尺度补偿。

### 图注草稿 3：尺寸分层检测结果

**表 X. `0705/b5-3` 在均衡场景子集上的尺寸分层检测结果。**
为验证性能提升是否来自小目标检测能力增强，进一步按照目标最大边长划分为 `1–4 px`、`5–8 px`、`9–16 px` 和 `>16 px` 四个尺度区间，并统计各区间的 AP50。结果显示，当前均衡场景子集在 `5–8 px` 区间取得 `0.443` 的 AP50，在 `9–16 px` 区间达到 `0.720`，而 `>16 px` 区间达到 `1.000`。由于该子集中未包含 `1–4 px` 样本，因此现阶段尚不能直接证明该模型对极微小目标的提升幅度，但可以确认其对 `5–16 px` 小目标已具备稳定检测能力。

### 分析段落草稿 1：MDHIFI 结果分析

从空间门控可视化结果来看，MDHIFI 并不是简单地提升整体响应强度，而是表现出明显的场景依赖性增强特征。基于均衡场景子集统计，MDHIFI 的平均 TCRR 在 `urban-areas` 场景中达到 `1.306`，在 `jungle` 场景中达到 `0.975`，显著高于 `cn_sky` 场景的 `0.591`。这说明 MDHIFI 在复杂纹理背景中能够更有效地区分目标与背景，通过梯度分支和纹理分支对弱小目标进行补偿，而在低纹理、低杂波的天空场景中，其增强作用相对温和。该现象与模块设计是吻合的，即 MDHIFI 更偏向于在“目标易被背景淹没”的区域提供自适应强化，而非对所有区域进行均匀增亮。

### 分析段落草稿 2：HFSCC 结果分析

HFSCC 的证据重点不在于通用热图是否更亮，而在于跨尺度一致性图是否能够将补偿集中到真实目标区域。实验统计表明，HFSCC 的 `c4` 一致性图在 `urban-areas` 和 `cn_mountains` 场景中的平均 TCRR 分别达到 `2.420` 和 `2.301`，明显高于 `building` 场景的 `1.745` 与 `cn_sky` 场景的 `1.695`。这表明当背景中存在建筑边缘、山地纹理或多尺度结构干扰时，HFSCC 能够更充分地利用相邻尺度间的一致性信息，为真实目标提供补偿，而对缺乏跨尺度支持的背景杂波进行抑制。相比之下，`c5` 的 TCRR 整体较低，说明更高层的一致性图更偏向于全局语义约束，而 `c4` 才是本模型在小目标补偿中更直接、更有效的证据来源。

### 分析段落草稿 3：尺寸分层结果分析

尺寸分层结果进一步说明，当前模型的检测性能提升主要体现在 `5–16 px` 范围内的小目标，而不能仅凭整体 mAP 直接推断其已经覆盖到所有极微小目标尺度。在均衡场景子集中，`5–8 px` 区间的 AP50 为 `0.443`，`9–16 px` 区间提升到 `0.720`，说明模型随着目标尺寸增大能够获得更稳定的判别能力；而 `>16 px` 区间达到 `1.000`，表明较大目标已基本不是当前模型的主要瓶颈。需要指出的是，当前子集未包含 `1–4 px` 样本，因此本实验更适合支持“模型对小目标具有稳定增益”的结论，而不宜直接扩展为“模型已经显著提升极微小目标检测性能”的强结论。若后续需要进一步强化这一论点，应额外补充专门针对 `1–4 px` 样本的独立评估。

### 答辩口语版表述

本次可视化没有再把所有模块统一画成 CAM 热图，而是按模块机理分别展示。对于 MDHIFI，我们直接展示它的空间 Gate，因为它本身保留空间维度；对于 HFSCC，我们直接展示跨尺度一致性图 `c4/c5`，因为这才是真正反映补偿机制的证据。进一步结合 TCRR 统计可以看到，模型在 `urban-areas`、`jungle`、`cn_mountains` 这类复杂背景中的目标响应更集中，而不是单纯把整幅图整体点亮。尺寸分层结果也说明，当前提升主要集中在 `5–16 px` 的小目标范围内，而 `1–4 px` 这一档由于样本不足，暂时还不能下过强结论。因此，本组实验更有力地支持“模型通过空间门控和跨尺度补偿改善了复杂背景下的小目标表征”，而不是笼统地宣称“所有极小目标都显著提升”。
